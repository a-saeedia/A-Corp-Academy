# A Corp Academy

The educational platform dedicated to A Corp.

## Store App (demo)

A small vanilla JavaScript store app — no framework, no dependencies:

- Loads a catalog of store items (`storeItems`)
- Lets a shopper add items to a cart (`addToCart`)
- Tracks the cart contents (`shoppingCart`)
- Calculates the running total (`calculateTotal`)
- Renders the cart to the page (`displayCart`)

Open `index.html` in any browser to try it.

## Purpose

Lightweight, dependency-free examples like this one are built as learning material for the A Corp Academy — teaching the fundamentals (DOM, functions, state) before frameworks enter the picture.
